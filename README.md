A pre-token protocol radar with a convex value model. The board ranks 200 pre-token protocols by an implied value derived only from the snapshot's own figures — TVL, seven-day growth and the time run without a token. Sustained growth compounds into value; contraction is discounted harder. Live-token protocols are set aside with their market caps. Every row carries a category-aware, six-step farm plan, and the dashboard offers search, category filters and a per-protocol model breakdown.

## Run it

```sh
node main.ts --input ../input/snapshot.json
```
